# 치이카와 코인 대모험

브라우저에서 즐기는 2D 자동 달리기 게임 프로토타입입니다.

## 실행

`dist/index.html`을 브라우저에서 열거나, Node.js 설치 후 다음 명령을 실행합니다.

```sh
node server.cjs
```

http://127.0.0.1:4173 에 접속합니다. 외부 패키지 설치는 필요 없습니다.

## 조작과 규칙

- 스페이스바 / 위쪽 화살표 / 화면 터치: 점프. 공중에서 한 번 더 누르면 2단 점프.
- P 또는 화면 버튼: 일시정지.
- 체력 3개로 시작하며, 30초씩 총 4개 스테이지를 통과하면 클리어합니다.
- 일반 코인 10점, 별 코인 100점, 무지개 코인 300점과 5초 피버.
- 피버 중 공중 고속 비행, 무적, 코인 자동 수집.
- 보호막: 한 번 방어 / 자석: 7초 자동 수집 / 하트: 체력 1 회복.
- 20콤보마다 점수 배율 상승, 최대 3배. 스테이지 전환 500점, 최종 클리어 2,000점.
- 최고 점수는 브라우저 로컬 저장소에 저장합니다.

## 스테이지

1. 아침의 버섯 마을
2. 오후의 과자 언덕
3. 노을빛 구름 다리
4. 밤의 별빛 축제

## 검증

```sh
node test-game.cjs
```

점프 제한, 화면 경계, 피버 충돌 보호, 아이템, 체력, 콤보, 스테이지 전환, 일시정지, 클리어와 재시작의 자동 회귀 검사를 실행합니다.

## 에셋

캐릭터 이미지는 내장 이미지 생성 도구로 만든 비공식 팬 게임용 에셋입니다. 생성 프롬프트는 `sprite-prompt.txt`에 있습니다. 치이카와 캐릭터에 관한 권리는 원권리자에게 있으며, 공식 제휴 프로젝트가 아닙니다.
